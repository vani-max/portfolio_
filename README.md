## 🚀 How to Run Locally

You can preview the portfolio immediately using Python's built-in HTTP server:

```bash
# In this directory:
python3 -m http.server 8000
```

Then open your browser at:
```
http://localhost:8000
```

Or simply double-click and open `index.html` directly in Google Chrome, Safari, or Brave!

## 🚢 Deploy to Production in 1 Minute

### Option A: GitHub Pages
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Vani Vashishtha portfolio"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` and root `/`.
   - Click **Save**. Your site is live!

### Option B: Vercel / Netlify
1. Drag and drop the `portfolio_` directory onto [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
2. It deploys automatically in seconds with zero build steps required.
